# Fastech Pakistan Wedding Templates

Five distinct Pakistan wedding website templates, built from Pakistani
wedding-makers research. All demo data only.

Live showcase: https://agoodworker.github.io/fastech-pakistan-wedding-template/

Each template has its own palette, fonts, hero, gate, section order, couple,
dates, venue and photos — no visual repeat across templates.

## What every template includes

Multi-day Pakistani events, per-event venue + map + dress code + calendar,
per-event household RSVP with no login/app via WhatsApp, English + Urdu toggle,
personal guest link, travel & stay, gallery, FAQ, wishes, seating/purdah note,
live-stream note, and a privacy-safe salaami line in FAQ only (no payment link).

## Demo disclaimer

Couple names, venues, dates, photos and host number in these templates are
demo data only. Replace them with the real couple's details on order. Photos
are stock demo photos, not the real couples.
