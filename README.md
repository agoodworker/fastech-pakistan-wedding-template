# Fastech Pakistan Wedding Template (Sample)

A sample Pakistan wedding website template, built from India/Pakistan
wedding-website research.

Live site: https://agoodworker.github.io/fastech-pakistan-wedding-template/

## What this sample includes (demo data only)

- Tap-to-open gate with Bismillah
- Hero with the complete Surah Ar-Rum 30:21 (full Arabic + translation)
- Six events: Dholki, Mayoun, Mehndi, Nikah, Barat, Walima — each with
  time, venue, dress code, map link and calendar download
- Per-event household RSVP with no login/app, via the host's WhatsApp
- English / Urdu (Nastaliq) toggle for the whole page
- Personal guest link (?guest=Name), elders' printed-card QR bridge note
- Purdah / seating notes on Nikah and Walima
- Gallery, Duas & Wishes, FAQ

## Demo disclaimer

Couple, venues, dates and host number in this sample are demo data only.
Replace them with the real couple's details on order. No salaami payment
link is included.
